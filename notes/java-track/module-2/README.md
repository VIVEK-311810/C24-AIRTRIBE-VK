# Backend - Java Track - Module 2

Dates: 2026-10-18 to 2026-10-25

## Module description

1. Java Fundamentals - 1
We will build a strong Java foundation starting from internet basics, Java setup, data types, variables, operators, loops, conditionals, and gradually advance into Object-Oriented Programming concepts like classes, objects, constructors, and memory handling.

We will focus on practical understanding through demonstrations, problem-solving, clear explanations, and structured content to ensure every concept—from syntax to OOP—is easy to grasp and ready to apply in real-world development.

2. Java Fundamentals- 2
Review of core Java fundamentals including typecasting, wrapper classes, operators, control flow, loops, methods, and constructors with practical examples.
Hands-on learner management system project reinforced concepts like classes, arrays, collections, encapsulation, and data validation through implementation and code reviews.
Discussion on real-world practices, importance of strong fundamentals despite AI tools, and upcoming topics like Java internals, design patterns, and concurrency.
