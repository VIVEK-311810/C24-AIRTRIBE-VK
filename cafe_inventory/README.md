# Campus Cafe Inventory Manager

Starter files for the project. Fill in every TODO in `Product.java` and `Main.java`.

## Setup

```
cd cafe_inventory
javac *.java
java Main
```

`Warmup.java` is a scratch file. Predict its output first, then run it with `java Warmup`.

Each TODO has a checkpoint in the brief. Run the program after each step.
